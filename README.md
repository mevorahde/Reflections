# Version-Control Course Reflections

This historical learning repository contains written reflections from an
introductory Git and GitHub course completed in 2018. The text files cover
version history, repositories, staging, commits, branches, remotes, forks, and
collaboration concepts as I understood them during the course.

## Contents

- `lesson_1_reflections.txt` — diffs and version-history concepts
- `lesson_2_reflections.txt` — repositories, staging, commits, and branches
- `lesson_3_reflections.txt` — reserved course file
- `lesson_3_reflections_github.txt` — remotes and GitHub collaboration

## Status

These files are preserved as a learning record, not as current Git
documentation. Some terminology, explanations, and recommended practices may
be incomplete or outdated. For a maintained command reference, see my
[Git Cheat Sheet](https://mevorahde.github.io/Git_Cheat_Sheet/).
